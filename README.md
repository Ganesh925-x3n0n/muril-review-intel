# muril-review-intel

> Multilingual review intelligence for Indian e-commerce — sentiment classification, fake review detection, and aspect-based sentiment analysis powered by a fine-tuned MuRIL transformer.

---

## What It Does

Indian e-commerce reviews are written in Tamil, Hindi, English, and code-mixed variants like Tanglish and Hinglish. Standard NLP tools fail on this text. This project fine-tunes Google's **MuRIL** (Multilingual Representations for Indian Languages) to handle all of it — simultaneously, in one system.

Given a review like *"Delivery super fast tha, but quality ekdum bakwaas hai"*, the system returns:

| Task | Output |
|---|---|
| **Sentiment** | Negative (78.4% confidence) |
| **Authenticity** | Genuine (91.2% confidence) |
| **Delivery aspect** | 👍 Positive (84.0%) |
| **Product Quality aspect** | 👎 Negative (81.6%) |

---

## Architecture

```
User Input (Tamil / Hindi / English / Code-Mixed)
        │
        ▼
  Flask Server (server.py)
   ├── POST /predict  →  MuRIL Dual Classifier
   │                      ├── Sentiment Head  (pos / neg / neu)
   │                      └── Fake Head       (genuine / fake)
   │
   └── POST /absa     →  MuRIL ABSA Model
                          ├── Product Quality Head
                          ├── Delivery Head
                          ├── Customer Support Head
                          └── Value for Money Head
```

Both models share the same `google/muril-base-cased` encoder backbone but are trained independently and served through a unified `/full` endpoint.

## Project Structure

```
.
├── train.py            # Fine-tune MuRIL dual classifier (sentiment + fake)
├── predict.py          # Inference for dual classifier — CLI, batch CSV, or server mode
├── absa_train.py       # Fine-tune MuRIL ABSA model (weak supervision + training)
├── absa_predict.py     # Inference for ABSA — with rule-based fallback
├── server.py           # Unified Flask server exposing all endpoints
├── index.html          # Web dashboard (open in browser after starting server)
├── muril_review_model/ # Saved dual classifier weights (generated by train.py)
└── muril_absa_model/   # Saved ABSA model weights (generated by absa_train.py)
```

## Quickstart

### 1. Install dependencies

```bash
pip install transformers torch flask flask-cors pandas scikit-learn numpy
```

### 2. Prepare your dataset

Your CSV needs these columns:

```
text, sentiment_label, fake_label
"Great product!", positive, genuine
"Worst quality ever", negative, fake
```

`sentiment_label`: `positive` / `negative` / `neutral`  
`fake_label`: `genuine` / `fake`

### 3. Train the dual classifier

```bash
python train.py --data your_data.csv --output muril_review_model --epochs 5
```

### 4. Train the ABSA model

```bash
# Auto-labels aspect data with weak supervision, then trains
python absa_train.py --data your_data.csv --output muril_absa_model
```

### 5. Start the server

```bash
python server.py
```

### 6. Open the web UI

Open `index.html` in your browser. That's it.

## API Reference

All endpoints accept `{"texts": ["review text here"]}` or a list for batch processing.

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Model load status |
| `POST` | `/predict` | Sentiment + authenticity |
| `POST` | `/absa` | Aspect-based sentiment |
| `POST` | `/full` | Both combined in one call |

**Example:**

```bash
curl -X POST http://localhost:5000/full \
  -H "Content-Type: application/json" \
  -d '{"texts": ["Delivery was fast but quality is very poor"]}'
```

**Response:**

```json
{
  "results": [{
    "text": "Delivery was fast but quality is very poor",
    "sentiment": "negative",
    "sentiment_confidence": 82.3,
    "authenticity": "genuine",
    "authenticity_confidence": 88.7,
    "aspects_detected": ["delivery", "product_quality"],
    "aspect_sentiments": {
      "delivery":        { "label": "positive", "confidence": 84.1, "source": "ml" },
      "product_quality": { "label": "negative", "confidence": 79.6, "source": "ml" }
    },
    "absa_summary": "Delivery: 👍 positive (84%) | Product Quality: 👎 negative (80%)"
  }]
}
```

## ABSA: Aspects and Fallback

Four aspects are analysed per review:

- **Product Quality** — build, material, durability, defects
- **Delivery** — shipping speed, packaging, courier condition
- **Customer Support** — returns, refunds, seller responsiveness
- **Value for Money** — price, worth, affordability

When ML confidence for an aspect drops below **60%**, the system automatically falls back to rule-based keyword scoring. The response includes a `"source"` field (`"ml"` or `"rule-based"`) so you always know which mechanism produced each prediction.

## Performance

| Task | Model | Accuracy / F1 |
|---|---|---|
| Sentiment Classification | MuRIL fine-tuned | 88.7% accuracy |
| Fake Review Detection | MuRIL dual head | 91.3% accuracy |
| ABSA (avg across 4 aspects) | MuRIL ABSA | 81.7% macro F1 |
| ABSA (rule-based baseline) | Lexicon only | 53.3% macro F1 |

Trained on 1,495 multilingual reviews across English, Tamil, Hindi, and code-mixed text.
